# Gurlal(35116633) Jar File Instructions
- Navigate to File in the IntelliJ Main Menu, then go to project structure.
- After choosing project structure it will open a windows, from there click on the artifacts buttons and then the plus on the right side of the Project Settings.
- After clicking the plus button choose Jar -> From Modules from dependencies, after that choose the Main Class of your code, name you Jar file then press Ok -> press Apply and then OK on the project structure window.
- Then after the window closes choose the Build button in the Main Menu button, then choose Build Artifacts and choose the Jar file you made in last step and choose the Build Action after wards.
- Lastly, the Jar file has been produced and all you have to do is find the out folder generated and copy it to Desktop or go to the folder the Jar file is in and double click to run and test it.
